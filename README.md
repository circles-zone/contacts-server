# contacts-server

Node.js backend server using Apollo GraphQL and TypeScript.

## פקודות בסיסיות

- התקנת תלויות:
  ```bash
  npm install
  ```
- הרצת פיתוח:
  ```bash
  npm run dev
  ```
- הרצה רגילה:
  ```bash
  npm start
  ```

## תיאור

שרת Apollo GraphQL בסיסי, מוכן להרחבה עם MySQL ו-MongoDB בשלבים הבאים.
